# Bilal Tufail Portfolio

A resume-based portfolio built with Next.js, Tailwind CSS, and Framer Motion.

## Update the content

Edit the section-specific files in `data/` to update the website. Shared content, including social links, lives there too. Replace `public/bilal-tufail-resume.pdf` to update the downloadable resume.

## Run locally

```bash
npm install
npm run dev
```
